## Praktiskt för nästa session

- **Lokal dev med AI:** starta dev-servern på port 3020 med `AI_PROVIDER=relay`, via launch-konfigurationen `frontend-3020-relay`. Varje AI-anrop hamnar som en fil i `AI_RELAY_DIR/requests/`, och den som testar (en människa eller Claude) svarar med `node frontend/scripts/ai-relay.mjs answer <id> <svar.json>`. Ett påtvingat verktyg kräver ett `tool_use`-block med verktygets namn.
- **Lokalt `CRON_SECRET`:** för att testa cron-routes lokalt, sätt `CRON_SECRET=localtest` i dev-serverns miljö.
- **Testkonton i den lokala databasen:**
  - `inga.test@example.test` leder `promenadkompis-hasselby`.
  - `anna.test@example.test` leder lånebåtsklubben i Vällingby.

  Gör dem tillfälligt till admin eller följare i ett projekt för att testa, och ta bort raderna efteråt.
- **tsc med minnesgräns, en körning i taget:** `NODE_OPTIONS=--max-old-space-size=3072 npx tsc --noEmit`.
- **Jest-tester som importerar `@/auth`** (via `lib/authz`) behöver `jest.mock("../auth", …)`. Annars blir jest hängande efter körningen.
- **Rebase:** Niklas har ocommittade lokala filer i trädet, så använd `git rebase --autostash origin/main`. Stagea alltid filer med namn.
- **Server actions:** `revalidatePath` i en server action ritar om den aktuella sidan. Det tar bort klientkomponenter som visas villkorat, som `FirstTaskPrompt`, innan deras bekräftelse hinner synas.
